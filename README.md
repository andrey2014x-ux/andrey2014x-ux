- 🤖 **Автономные AI-боты в Telegram**: Разработка умных ассистентов на базе Claude 3.5 Sonnet и GPT-4o с корпоративной базой знаний (RAG) для квалификации и записи клиентов 24/7.

- 📊 **B2B-парсинг и AI-скоринг**: Законный сбор открытых данных компаний (Яндекс.Карты, 2ГИС) по 149-ФЗ с параллельным анализом сайтов через LLM.
